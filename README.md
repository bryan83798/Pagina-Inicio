## 🎮 Projeto de TCC: Jogo Tetris

Desenvolvimento de uma versão interativa do clássico jogo **Tetris**, focando em lógica de jogos e integração com banco de dados em nuvem e local.

### 🚀 Funcionalidades
- **Mapeamento de Blocos:** Lógica de movimentação, rotação e colisão das peças.
- **Pontuação em Tempo Real:** Armazenamento de histórico e pontuações máximas via **Firebase**.
- **Servidor Local:** Testes e persistência de dados complementares via **XAMPP**.

### 💻 Tecnologias Utilizadas no TCC
- **Linguagem:** Dart
- **Banco de Dados:** Firebase & XAMPP (MySQL)
- **IDE:** Visual Studio Code
